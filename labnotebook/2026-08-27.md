## Trajectry schema options

Trajectory = one continuous block, one environment, uniform dt

stored arrays, all length T:
  t        float64   seconds, t[k] = k * dt
  pos      float64   (T, 2), meters, room frame
  heading  float64   radians, wrapped to [-pi, pi)
  vel      float64   (T, 2), m/s        derived
  speed    float64   m/s                derived
  ang_vel  float64   rad/s              derived
  phase    uint8     per-timestep label (run, dwell, return, forage, cued)
  trial    int32     -1 before first run, else cycle index
  route    int16     -1 outside runs, else route index

meta, json sidecar next to the npz:
  schema_version, source (synthetic or real)
  env_name, env_hash, dt
  heading_source (tangent or led)
  phase_names, route_names   the label mappings
  seed path and resolved generator params, or raw checksum and cleaning params
  derive_version and its settings

`data/<cohort>/<animal>/<session>.npz`

## OOPS
1. environment: geometry, from configs/environments/
2. trajectory: where the agent was, when, facing where. Generated or loaded.
3. session: trajectory blocks plus rendered input cell rates, one npz in data/
4. animal: one input ensemble draw and its sessions
5. cohort: a group of animals, defined by one config
6. run: one trained network on a cohort's manifest

flow: config → env spec → trajectory → cell rates → session files → manifest → training.

Thoughts on: read Doug's format, clean, register, resample, emit this schema. this will be a one time data munging script 

Seed strategy: Seed strategy, concrete: numpy SeedSequence tree, default_rng everywhere, never global numpy state in our code..... Cohort config carries a root seed per animal. Animal spawns named children in fixed order: population draw, then one per session. Each session spawns its own children: trajectory now, cell noise later. Every file's metadata records its full spawn path, so any single session regenerates in isolation. The test: same seed, byte-identical arrays. One known wart for later: RatInABox uses global np.random internally, so when cells arrive we seed the global RNG immediately before rendering and log that seed.
